# Сайт-навигатор «Как быть, когда сложно»

## Что в комплекте

- `index.html` — готовый сайт, один файл. Открывается в любом браузере, работает без интернета (без интернета вместо фирменного шрифта будет системный).
- `source/content.md` — весь текст сайта: промт и база знаний. Карточки сайта собираются из раздела «# БАЗА ЗНАНИЙ».
- `source/template.html` — оформление и логика сайта: поиск, таймер паузы, роли, вход через чувство, короткие блоки, экстренная помощь.
- `source/build.py` — сборщик: берёт текст из `content.md`, вставляет в `template.html` и сохраняет готовый `index.html`.

## Как поменять текст

1. Отредактируй `source/content.md`. Правила разметки:
   - `## 6. Название` — раздел;
   - `### А1. Название`, `### П1. Название`, `### 8.2. Название` — карточка;
   - `- пункт` — список, `**жирный**`, `«фраза длиннее 18 символов»` — получит кнопку «копировать»;
   - ссылки вида `А4`, `П3`, `раздел 9` превращаются в переходы автоматически;
   - строки, начинающиеся с имени (`**Виктору нельзя:** …`), подсвечиваются для выбранной роли.
2. Собери сайт (нужен Python 3):

   ```
   cd source
   python3 build.py content.md template.html ../index.html
   ```

## Что правится прямо в template.html

- Короткие блоки «Коротко» для карточек А1–А15 — объект `SHORT`.
- Кнопки «Что ты сейчас чувствуешь?» — массив `FEELS`.
- Плитки на главной: общие — `TILES`, для Виктора и Виктории — `TILES_ROLE`.
- Шаги режима «Сейчас конфликт» — массив `STEPS`.
- Кодовые сигналы — `CODES`, варианты паузы — `DURS`.
- Номера экстренной помощи — блок `helpModal` в разметке (и раздел 16 в `content.md`).
- Синонимы для поиска по карточкам — словарь `SYN` в `build.py`.

## Где разместить

- Как артефакт Claude — уже опубликован.
- На любом статическом хостинге (например, Netlify): загрузить `index.html`. Там можно будет добавить сайт на экран телефона как приложение.

## Что хранится и где

Избранное, недавние карточки, выбранная роль, отметки в чек-листах, тема и запущенный таймер хранятся только в браузере на конкретном устройстве. Другому человеку и на другие устройства они не передаются.
